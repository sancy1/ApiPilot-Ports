apipilot — ApiPilot for Python.

Framework-neutral core (envelopes, error codes, pagination, validation keys, origin, fetch-metadata, cookie rules, CSRF format and binding) plus an optional ASGI adapter (apipilot.asgi) covering FastAPI, Starlette, and ASGI-capable Django.

The core has zero dependencies. Install the adapter with:

pip install "apipilot[asgi]"
