apipilot.asgi package¶

Pure ASGI middleware implementing the full ApiPilot pipeline. Works with FastAPI, Starlette, Django (ASGI), and any ASGI framework.

apipilot.asgi — the ASGI adapter for ApiPilot.

Pure ASGI middleware covering FastAPI, Starlette, and any ASGI-capable framework (including Django via its ASGI handler). The core logic lives in apipilot (framework-neutral); this subpackage is the HTTP binding.

Install with:

pip install "apipilot[asgi]"
